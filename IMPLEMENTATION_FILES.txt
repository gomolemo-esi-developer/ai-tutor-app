ENDPOINTS CREATED
═════════════════

/api/rag/settings/ (Backend Proxy)
──────────────────────────────────

GET /config
  - Fetch all current settings
  - Response: All 9 settings + available models

POST /model
  - Update LLM model
  - Body: {model_id: string}
  - Validates: model exists in available list

POST /temperature
  - Update temperature
  - Body: {temperature: number}
  - Validates: 0.0 ≤ temp ≤ 2.0

POST /embedding
  - Update embedding model
  - Body: {embedding_model: string}

POST /retrieval
  - Update top-k documents
  - Body: {top_k: number}
  - Validates: 5 ≤ top_k ≤ 100

POST /prompts
  - Update system and quiz prompts
  - Body: {custom_prompt?: string, quiz_prompt?: string}

POST /offline
  - Toggle offline mode and configure LM Studio
  - Body: {offline_mode: boolean, lm_studio_url?: string, lm_studio_model?: string}

/api/settings/ (RAG Service)
─────────────────────────────

Same 7 endpoints on RAG service, all with persistence to .env
